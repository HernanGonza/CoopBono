- This is a client-side Vite + React SPA deployed on Vercel (see vercel.json). There is no SSR or server code.
- Keep the commercial proposal in src/App.tsx with anchor navigation, because its sections form one presentation.
- Keep fictional demo data and calculation helpers in src/lib/mockData.ts, because the demo must remain editable and independent of services.
- Keep demo state in React and lazy-load the Leaflet map with React.lazy, because data must remain ephemeral and Leaflet is heavy.
- Define presentation styles and semantic colors in src/styles.css and button variants in the shared Button, because the proposal needs a consistent visual system.
